How to feed it from your phone

  1. Screen time, nightly (30 sec): Settings → Screen Time → See All App & Website Activity → screenshot → Today → Add screenshot → Log it. If it shows yesterday, the app files it under yesterday. A new import replaces that day’s old one.
  2. What you saw: when a post, reel or video sticks with you, screenshot it and add one line on why. Over a week you see what is shaping your head.
  3. Brain dump: tap the keyboard mic and just talk: what you did, ate, felt, who you met, what you made.
  4. Energy and mood: one tap each, morning and evening.
  5. Sunday: rate the wheel, then tap “Review my week”.
  6. Home screen: open this page in Safari, tap Share → Add to Home Screen. Use the home screen icon from then on: it keeps its own storage.

Claude

The mentor runs on your own Anthropic API key. It is stored only on this device and sent only to api.anthropic.com. Get one at console.anthropic.com → API Keys. Rough cost: a few cents per mentor answer or screenshot read (estimate).

Quick text logs use Claude Haiku 5.5 to sort entries. Day reads, screenshots, chat and the weekly review use the mentor model.

Setup code or backup

Paste a setup code or a backup file’s contents to load a profile, chat and log onto this device.

Your data

Everything stays on this device, in this app’s storage. There is no server and no account. Screenshots go once to Claude to be read and are not stored, only what was extracted. Export a backup every week or so: deleting the app or clearing Safari data deletes your ledger.
